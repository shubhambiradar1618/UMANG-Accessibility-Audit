# Tests

This directory contains testing resources for the project.

## Testing Areas

- Accessibility testing
- Keyboard navigation testing
- Frontend testing
- Backend API testing
- Integration testing

## Accessibility Testing

Accessibility testing will verify:

- Keyboard navigation
- Visible focus indicators
- Accessible names
- Heading hierarchy
- Semantic landmarks
- Color contrast
- Screen-reader compatibility

## Future Testing

Automated accessibility testing and API tests can be added
as the project develops.
